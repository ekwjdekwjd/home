# files 폴더 안내

이 폴더에는 자료실(archive.html)에서 내보낸 `manifest.json`과, 실제로 다운로드 가능하게 만들 파일들을 함께 올려주세요.

## 사용 방법
1. `archive.html`에서 파일을 첨부해 목록을 정리합니다.
2. "manifest.json 내보내기" 버튼을 눌러 `manifest.json`을 받습니다.
3. 받은 `manifest.json`으로 이 폴더의 `manifest.json`을 덮어씁니다.
4. `archive.html`에 첨부했던 실제 파일들을 (원본 그대로, 파일명 동일하게) 이 폴더에 함께 넣습니다.
5. 변경사항을 깃허브 저장소에 커밋 및 푸시합니다.

파일명이 `manifest.json`에 적힌 이름과 정확히 같아야 홈페이지(index.html)에서 다운로드 링크가 정상적으로 연결됩니다.
